# Foxuma — Case Study

A one-page case study: how Foxuma runs the daily work of a custom cabinetry and millwork shop in Concord, Ontario.

Live (planned): https://marksong0917.github.io/case-study/

## What it is

A standalone static page — no build step, no JavaScript required:

- `index.html` — the page
- `styles.css` — white / navy `#0d1526` / orange `#e85d1f`, Sora + Inter

Sections: hero → the shop → before/after → a day with Foxuma → what runs in Foxuma (modules) → why it matters to another shop owner → demo CTA.

## Honesty rules for this page

- The shop is **not named**, and no person is named. It is described only as "a custom cabinetry and millwork shop in Concord, Ontario."
- **No numbers are claimed** — no revenue, no invoice totals, no percentages, no "hours saved." The before/after is written as workflow truth, not measured metrics.
- Only public-safe facts are stated: Foxuma handles projects/orders, customers, invoicing, payroll hour tracking with punch-card photos, inventory from supplier invoices, the Fox assistant answering from company records, role-based accounts, and it runs on the shop's own server in Canada, used daily by the whole team.

Keep it that way in edits: if a claim can't be said without inventing a number or naming the business, don't add it.
