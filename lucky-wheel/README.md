# 大转盘 · Lucky Wheel

免费在线大转盘：自己填选项，转一转帮你做决定 — 今天吃什么、班级点名、是或否，都可以。每个选项机会均等，完全公平随机；结果会记进历史记录。**选项只保存在你的浏览器里，不上传。**

A free lucky wheel that runs entirely in your browser. Add your own options and spin to decide — what to eat, a classroom pick, yes or no. Every option gets an equal chance, and results are kept in a spin history. **Options are saved locally in your browser; nothing is uploaded.**

**Live:** https://marksong0917.github.io/lucky-wheel/

## 功能 / Features

- 自定义选项，每行一个，2–24 个 / Custom options, one per line, 2–24 entries
- 三个快捷预设：今天吃什么、班级点名、是或否 / Three presets: What to eat, Classroom pick, Yes or no
- 公平随机：先均匀抽中赢家，转盘再缓缓停在它上面 / Fair draw — the winner is picked uniformly at random, then the wheel eases to a stop on it
- 指针所指与宣布结果永远一致 / The announced result always matches the segment under the pointer
- 历史记录保留最近 10 次结果 / Spin history keeps the last 10 results
- 选项自动保存在本机 / Options persist in localStorage
- 中英双语界面 / Bilingual EN / 中文 UI

## 技术 / Tech

纯静态站点（HTML / CSS / 原生 JS + Canvas），无构建步骤，加载后可完全离线运行。

Plain static site (HTML / CSS / vanilla JS + Canvas), no build step, fully offline after load.
