A Personal Project — Game Server

Legend of Mir 2 — a classic, kept alive.

A self-built 1.76 server, hosted at home and running 24/7. No company, no hosting provider — one machine, one pair of hands, and a game worth keeping online.

Status: Running 24/7

Why 1.76

Version 1.76 is the Legend of Mir 2 that people remember — the maps, the items, the balance, the pace. Later versions changed the game; 1.76 is the one a generation of players grew up with.

This server exists to keep that version running as it was. Not remixed, not modernised — the classic game, kept alive on purpose, for the people who still love it.

What it takes

Running a game server from home is a systems job: a full stack to configure, a machine that never sleeps, and data you cannot afford to lose. This is the part that is really a portfolio piece.

Full server stack

The whole pack — game server, gates and database — set up and configured by hand. Every piece has to agree with the others before the first player can log in.

Always on

The server runs on a dedicated machine at home. Services start on their own, and a watchdog notices and recovers them if anything stops — day or night.

Backups

Character and world data is backed up to a second machine on a schedule. If the main machine ever failed, the world — and everyone's progress — would survive it.

Careful changes

Updates are tested before they go live, never pushed straight onto the running world. And when a restart is needed, players get a warning in game first — nobody loses a fight to a surprise shutdown.

Private by design

This page is the story of the project, not a doorway into it. The server is private: there is no client download, no sign-up and no address published here — deliberately.

If you are curious about the build, the hosting, or keeping an old game alive, the one way to reach it is an email.
